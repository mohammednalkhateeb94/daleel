# دليل

«دليل» يوصل المبتدئ الناطق بالعربية من سؤاله عن القرآن الكريم إلى **المقطع المعتمد** الذي يجيب عنه: نص حرفي من مصدر معتمد، مع موضعه ورابطه، ثم يسأله «هل أجاب؟» ويتابع معه «ما الذي بقي؟». لا يكتب إجابات شرعية من عنده، ويمتنع ويحيل خارج نطاقه.

مشاركة في «تحدي الذكاء الاصطناعي في خدمة المحتوى الإسلامي» (المسار الثالث).

## كيف يعمل

1. **فحص بقواعد** (`app/precheck.py`): الفتوى، وطلب الحديث، وتفسير آية، والقراءات، والإعجاز العلمي، والنص غير العربي، والأسئلة خارج القرآن → امتناع بقالب مراجَع. الآية المكتوبة في السؤال تُطابق مع المصحف ويُعرض نصها الصحيح.
2. **الموجِّه** (`app/router.py`): النموذج اللغوي يرى **أوصاف** المقاطع المعتمدة فقط ويعيد قراراً مقيداً عبر أداة: مقطع / استيضاح / امتناع مع السبب. لا يكتب أي نص يراه المستخدم.
3. **بوابة القواعد** (`app/engine.py`): لا يمر إلا مقطع موجود في المكتبة المعتمدة، مستواه أ أو ب، وملاءمته كافية.
4. **العرض**: كل نص يراه المستخدم من السجل أو من قوالب مراجَعة.
5. **البديل عند التعطل** (`app/fallback.py`): مطابقة BM25 على المكتبة نفسها، مع قائمة الأسئلة.

## المكتبة

- السجل: `data/register.xlsx`. كل جديد يدخل ورقة «للمراجعة»، وبعد قرار المراجع (ورأي المختص الأعلم للحساس) ينقله `python scripts/promote.py` إلى «المقاطع» أو «القوالب» مع ملاحظة الاعتماد، أو إلى «المرفوض» مع السبب. المنتج لا يقرأ إلا المعتمد.
- التصدير: `python scripts/export_register.py data/register.xlsx` يعيد فحص شروط النشر بنفسه ويكتب `data/segments.json` و`data/export_report.json`.
- الآيات داخل المقاطع تُستبدل عند التصدير بنص مصحف مجمع الملك فهد.

## التشغيل

```bash
pip install -r requirements.txt
export ANTHROPIC_API_KEY=...   # بدونه يعمل المنتج بالبديل (BM25) مع تنبيه
uvicorn app.server:app --port 8000
python tests/test_offline.py
```

## الخصوصية

لا حسابات، ولا سؤال عن الدين. سجل القرارات (`logs/decisions.jsonl`) لا يحفظ نص السؤال، بل القرار والمقاطع والزمن والكلفة. يُرسل نص السؤال إلى مزوّد النموذج لفهمه فقط.
