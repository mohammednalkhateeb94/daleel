# دليل

«دليل» نظام توجيه معرفي مراجَع. يفهم ما يحتاجه المبتدئ من سؤاله عن القرآن الكريم، ثم يقرر: هل في المكتبة المراجَعة نص يجيب عنه فعلاً؟ فإن وُجد عرضه **حرفياً** مع مصدره وموضعه ورابطه، ثم سأل: «هل أجاب هذا عن سؤالك؟» وتابع ما بقي. وإن لم يوجد قال ذلك بصدق، أو استوضح، أو أحال.

لا يكتب «دليل» أي نص شرعي من عنده. النموذج اللغوي يختار أرقام مقاطع وجمل، ولا يكتب شيئاً يراه المستخدم.

مشاركة في «تحدي الذكاء الاصطناعي في خدمة المحتوى الإسلامي» (المسار الثالث).
الموقع: https://daleel-6cy6.onrender.com

## ما الذي يميّزه؟

البحث يعرض **أقرب** نص إلى كلمات السؤال. «دليل» يعرض **المناسب** لحاجة السائل، ويمنع النص القريب الذي لا يجيب:

- لكل مقطع في المكتبة «أسئلة قريبة لا يجيب عنها» كتبها المراجع، وهي بوابة منع قبل أي ترتيب (المطابقة السلبية).
- بعد اختيار المقطع يُفحص نصه نفسه: هل يجيب عن السؤال، أم عن جزء منه، أم لا يجيب؟ فإن لم يجب امتنع «دليل» بدل أن يعرض نصاً قريب الموضوع.
- يستوضح حين يغيّر المقصد المادةَ المناسبة («مين كتب القرآن؟» له ثلاثة مقاصد)، ولا يستوضح فيما سوى ذلك.
- يحيل الفتوى والحالة الشخصية إلى أهل العلم، ولا يجيب عنها.

| قياس السجل (195 سؤالاً من صياغات المقاطع وحدودها) | **191/195**، و83/83 في المنع | — | — | — |

- الفرق بين «دليل» وكل بديل دالّ إحصائياً (اختبار McNemar الدقيق: p = 0.039 و<0.001 و0.0005).
- **تنبيه صادق:** مجموعة التطوير ضُبط النظام عليها، فهي ليست قياساً مستقلاً. القياس المستقل يُجرى مرة واحدة على مجموعة تُكتب بعد تجميد النسخة v1.0، وتُنشر نتيجته كما هي.
- الزمن الوسيط نحو 3 ثوانٍ، والكلفة نحو نصف سنت للسؤال.

## كيف يعمل

```
السؤال
 → فحص بالقواعد: فتوى، طلب حديث، تفسير آية، قراءات، سؤال خارج القرآن، آية مذكورة بموضعها
 → الموجّه (نموذج لغوي يرى أوصاف المقاطع فقط): مقطع / استيضاح / امتناع بسبب
   ويسجّل وظيفة السؤال ومسألته وحساسيته (A–D)
 → البوابات: المعتمد فقط، والمطابقة السلبية، والحاجة نفسها
 → فحص نص المقطع: يجيب / جزئي / لا يجيب، واختيار الجمل التي تجيب
 → العرض: الجمل المتعلقة حرفياً + «أريد التفصيل» للنص كاملاً، مع المصدر والموضع
 → «هل أجاب؟» ثم: بقي جزء، المعنى غير واضح، لدي اعتراض، أريد المصدر، أريد مختصاً…
```

عند تعطل النموذج يعمل «دليل» ببحث BM25 على المكتبة نفسها، ويعرض النتيجة بعنوان «متعلق بسؤالك» مع تنبيه.

المنهجية الكاملة وما نُفّذ منها وما أُجّل: [docs/methodology.md](docs/methodology.md).

## المكتبة

- **34 مقطعاً** معتمداً تغطي سبع حاجات للمبتدئ، من ثلاثة مصادر: «بينات» (مركز أصول)، والموسوعة العقدية (الدرر السنية)، و«مباحث في علوم القرآن» لمناع القطان. والآيات من مصحف مجمع الملك فهد.
- كل مقطع راجعه صاحب المشروع، والحساس منها راجعه مختص أعلم.
- السجل `data/register.xlsx` مبني على مخطط المحتوى في المنهجية: ما يجيب عنه المقطع، وما لا يجيب عنه، ووظيفته، وحدود دليله، وما يرتبط به. النص المعتمد لا يُعدَّل، وما قُصّ منه موسوم بـ «[…]».
- كل جديد يدخل ورقة «للمراجعة». بعد قرار المراجع ينقله `scripts/promote.py`، ثم يصدّره `scripts/export_register.py` بعد أن يعيد فحص شروط النشر بنفسه.

## التشغيل

```bash
pip install -r requirements.txt
export ANTHROPIC_API_KEY=...      # بدونه يعمل «دليل» بالبديل BM25 مع تنبيه
export DALEEL_ADMIN_KEY=...       # يحمي تشغيل القياس
uvicorn app.server:app --port 8000
python tests/test_offline.py      # اختبارات بلا شبكة
```

القياس: `/api/eval/run?key=…&set=dev|register|heldout&systems=daleel,bm25,general,general_pre`، ثم `/api/eval/latest`.

## الخصوصية

لا حسابات، ولا سؤال عن الدين. سجل القرارات لا يحفظ نص السؤال، بل القرار والمقاطع والزمن والكلفة. يُرسل نص السؤال إلى مزوّد النموذج لفهمه فقط.

## القيود المعروفة

- المكتبة صغيرة (34 مقطعاً)، وفيها فجوات معلنة، مثل: «من أين أبدأ القراءة عملياً؟»، و«ما أول ما نزل؟»، و«ما الفرق بين القرآن والحديث النبوي؟». «دليل» يمتنع عنها ولا يعرض أقرب نص.
- في المتابعة، إن كان جواب ما بقي في المقطع المعروض قبلُ، يقول «دليل» إنه لم يجد جزءاً آخر، ولا ينبّه إلى المقطع المعروض.
- التكيّف بحسب معرفة السائل وعمق الجواب المطلوب موثق في المخطط ومؤجل.
- الخادم المجاني ينام بعد الخمول، فقد يتأخر أول سؤال.
