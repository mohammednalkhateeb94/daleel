# هوية «دليل»

الرمز: حرف الدال مرسوماً بخط واحد ينتهي بنقطة خضراء. المسار رحلة السائل، والنقطة المقطع المناسب الذي يصل إليه.

| الملف | الاستخدام |
|---|---|
| `daleel-logo-dark.svg` / `.png` | الشعار الأساسي على الخلفيات الداكنة (العرض، الفيديو، الموقع) |
| `daleel-logo-light.svg` / `.png` | على الخلفيات الفاتحة |
| `daleel-logo-white.svg` / `daleel-logo-black.svg` | طباعة بلون واحد |
| `daleel-mark.svg` | الرمز وحده على خلفية داكنة |
| `daleel-icon.svg` و `daleel-icon-*.png` | أيقونة التطبيق والمتصفح |

**قاعدة واحدة:** الرمز يكون دائماً داخل مربعه. الدال والنقطة دون المربع، بجانب كلمة «دليل»، تُقرأ «د.» (اختصار «دكتور»).
